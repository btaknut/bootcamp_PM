# KPI Source Mapping

## Source hierarchy
1. 협약/승인된 사업계획서 및 공식 변경문서
2. K-PASS/RCMS/학사·취업 등 공식 시스템
3. 공식 결과보고·전자결재 문서
4. Baseline Master/Core
5. 운영 Dashboard

## Mapping
M04 KPI는 지표 정의·단위·산식·연차목표를 보유한다. I01은 측정기간별 실적, I02는 해당 실적의 C05 Evidence 연결을 관리한다.

## Gate
Evidence가 없거나 Source Conflict가 존재하면 실적을 Verified로 확정하지 않는다.

## 현재 주요 Conflict
- 참여기업 44 vs 45
- 연구활동비 498 vs 565백만원
- 추가 고급 교육프로그램 1건
- 양성인원 등 사업계획서 총괄표/세부표 불일치 가능 항목은 공식 협약변경 기준으로 정리
