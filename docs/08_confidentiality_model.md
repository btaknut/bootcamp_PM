# Confidentiality Model

## L1 Public
공개 가능한 사업 소개·일반 구조·비식별 성과.

## L2 Internal
내부 운영 일정·업무분장·일반 회의/관리정보.

## L3 Confidential
미공개 예산검토·평가대응·협약변경 검토 등 제한 정보.

## L4 Restricted
학생 개인식별/진로, 주민등록번호, 계좌번호, 개인 연락처, 비공개 평가자료, 인증정보·토큰·비밀번호 등.

## 저장정책
GitHub에는 L4 원문을 저장하지 않는다. Notion도 Restricted 권한과 대학 Compliance Gate가 확인되지 않으면 L4 Migration을 수행하지 않는다. 공식시스템의 민감 원본은 해당 시스템에 유지한다.

## Public Repository 주의
현재 저장소가 Public인 경우 L1 및 비민감 설계문서만 허용한다. L2/L3 운영 세부정보를 추가하기 전 Repository 공개범위를 재검토한다.
