# Evidence Gate

성과·완료·집행의 공식 확정에는 근거가 필요하다.

## 최소 조건
1. 대상 Record 식별
2. Source 종류 식별
3. 공식 문서/시스템 위치 확인
4. 대상 기간·금액·인원 등 핵심값 일치
5. 승인/제출/집행 상태 확인
6. C05 Evidence Index 또는 공식 시스템 참조 연결

## 판정
- Verified: 근거와 값이 일치
- Conditional: 일부 근거만 확보
- Not Checked: 미대조
- Conflict: 서로 다른 공식/준공식 Source가 충돌

## 금지
파일 존재만으로 실적을 인정하지 않는다. 초안·계획·신청을 완료·승인·집행으로 간주하지 않는다.
