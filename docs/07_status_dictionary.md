# Status Dictionary

## Project/Task
- Planned
- In Progress
- Blocked
- Done
- Archived

## Data Status
- Draft
- Active
- Hold
- Conflict
- Verified
- Archived

## Budget Verification
- Not Checked
- Matched
- Mismatch

## Gate
- Open: 조건 미해소
- Conditional: 일부 조건 충족
- Closed: 검증 완료

상태명은 UI 표현과 데이터 의미를 분리한다. `Done`은 업무완료, `Verified`는 데이터 검증완료를 의미하며 상호 대체하지 않는다.
