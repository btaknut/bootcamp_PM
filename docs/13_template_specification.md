# Template Specification

S01 Templates는 반복 업무의 입력 품질을 통제한다.

## 공통 필수요소
- 목적/대상
- Owner
- Project/WP Relation
- 시작/마감일
- 상태
- 산출물
- Evidence 요구사항
- Confidentiality

## 주요 Template
- Project initiation
- Task/action item
- Meeting & decision
- Issue/source conflict
- KPI measurement
- Budget allocation/execution
- Education program
- Company participation

Template은 원천 데이터의 의미를 변경하지 않으며, 신규 Record의 최소 필드와 Gate를 일관되게 적용하기 위한 수단이다.
