# 저장 정책

## 저장 판정 순서
1. 자료가 L1인지 확인한다.
2. 원문이면 파일별 Allowlist 승인을 확인한다.
3. 개인정보·민감정보·인증정보를 검사한다.
4. 저작권과 재배포 권리를 확인한다.
5. 대상 경로가 신규인지 확인한다.
6. SHA-256과 Git Blob SHA를 기록한다.
7. 신규 브랜치에만 커밋한다.
8. main·PR·병합이 없음을 확인한다.

하나라도 충족하지 못하면 저장하지 않고 차단 기록으로 남긴다.

## 원문 정책
현재 파일별 공개저장 승인을 받은 원문은 0건이다. 첨부 PDF 14건은 본 단계에서 저장하지 않는다.

## 롤백
문제가 확인되면 신규 브랜치 ref의 추가 사용을 중지하고, Notion 신규 검증기록을 보관 또는 비활성화한다. 기존 main과 기존 파일은 롤백 대상이 아니며 변경되지 않아야 한다.
