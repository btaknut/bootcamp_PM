# 범위와 승인 Gate

## 목적
승인된 신규 구축 설계를 GitHub의 별도 브랜치와 별도 디렉터리에 안전하게 저장하는 기준을 정의한다.

## 허용 범위
1. EX-15 신규 L1 설계문서
2. 파일별 Allowlist가 확인된 L1 원문
3. 파일 해시, Git Blob SHA, 커밋 및 롤백 참조
4. 저장 전 보안·경로·재배포 검토 기록

## 금지 범위
- 기존 파일 수정 또는 덮어쓰기
- main 직접 변경, PR 생성, 병합
- L2~L4 또는 실데이터 저장
- 개인정보, 인증정보, 비공개 증빙 저장
- 기존 24 DB·Key·Phase·Baseline 복제
- 파일별 승인 없는 원문 저장

## Gate
모든 필수 검사가 통과하고 중대 오류가 0건이어야 한다. 미해결 항목은 확인 필요 또는 Exception으로 분리하고 공식값과 운영 전환에서 제외한다.
