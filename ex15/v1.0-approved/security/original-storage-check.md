# 원문 저장 보안 체크

## 현재 판정
- 공개저장 승인 원문: 0건
- 저장된 첨부 PDF: 0건
- 저장된 L2~L4: 0건
- 저장된 개인정보·인증정보·실데이터·비공개 증빙: 0건

## 파일별 Allowlist 필수 항목
- 승인 근거 Record ID
- 자료유형과 보안등급
- 공개저장 허용 여부
- 원천 식별자
- 저작권·재배포 확인
- 개인정보·민감정보 검사
- 인증정보 검사
- 대상 경로 충돌 검사
- SHA-256
- Git Blob SHA와 커밋 참조

승인이 공란이거나 검사 결과가 불일치이면 저장하지 않는다.
